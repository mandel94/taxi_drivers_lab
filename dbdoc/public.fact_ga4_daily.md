# public.fact_ga4_daily

## Description

Fact table GA4 in formato long: una riga per (article_id, metric_date, metric_name). Grain rigorosamente giornaliero: metric_date e' una singola DATE, non un intervallo. Strutturalmente impossibile memorizzare una misurazione su piu' di un giorno. Scritture idempotenti via INSERT ... ON CONFLICT (article_id, metric_date, metric_name) DO UPDATE.
